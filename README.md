
# NVCLI Commands

A lightweight, modular Bash command-line toolkit for Termux and Linux.

## Features

- Cross-platform environment detection
- System information
- Disk and memory information
- Network utilities
- Package repository updates
- Environment diagnostics
- Simple installation and removal
- Modular command architecture

## Requirements

- Bash 4.0+
- Termux or Linux
- Standard system utilities

## Installation

Clone the repository:

    git clone https://github.com/USERNAME/NVCLI-Commands.git

Enter the directory:

    cd NVCLI-Commands

Install:

    bash install.sh

Run:

    nvcli help

## Commands

| Command | Description |
|---------|-------------|
| help | Display help |
| version | Display version |
| info | System information |
| uptime | System uptime |
| disk | Disk usage |
| memory | Memory information |
| ip | Network addresses |
| ping | Connectivity test |
| update | Update package repositories |
| doctor | Environment diagnostics |

## Supported Platforms

- Termux on Android
- Linux distributions using supported package managers
